# AURA - your personal AI COMPANION


an AI companion that proactively learn your patterns and suggests you to do what next 



## FEATURES of AURA

- Remembers your goals and plans 
- morning briefing everyday day
- voice conversation
- proactive suggestions 


## SetUp 
1. clone this repo
2. pip install -r requirements.txt
3. add your API key to .env
4. python app.py
